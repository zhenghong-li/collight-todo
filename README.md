# 拾光 · MORI

一个住在 Windows 桌面上的本地日历待办。平时留在右下角查看本月安排，点击日期添加事项，需要集中整理时展开完整看板。

**[下载 Windows x64 安装包](https://github.com/zhenghong-li/collight-todo/releases/latest)** · [查看源码](https://github.com/zhenghong-li/collight-todo)

## 使用

在 [Releases](https://github.com/zhenghong-li/collight-todo/releases) 下载最新的 `Mori-Setup` 安装包，双击安装后从桌面快捷方式“拾光待办”打开。安装版无需另装 Node.js。升级会保留原有待办和自启动设置。

自行构建时，安装包位于 `release/`。也可以直接运行 `release/win-unpacked/Mori.exe`，但需要保留整个 `win-unpacked` 文件夹。

### 平时：桌面月历

- 默认以 **408 × 568** 的小窗口出现在主屏幕右下角，避开任务栏；每次启动先显示本月日历。
- **点击任意日期添加事项**，在小窗口中填写标题并保存。开始与结束日期相同表示单日事项；选择不同日期，事项就会显示在整个起止区间内，支持跨月、跨年。
- 有未完成事项的日期显示醒目的红点和浅红底色，同一天有多项时红点内显示待完成数量；全部完成后红点消失。事项标题保留所属清单的颜色，鼠标悬停可查看完整标题；下方列表显示选中日期的全部事项，可滚动查看、点击修改或直接勾选完成。
- 月份两侧的箭头切换月份，“今天”返回本月当天。上方可筛选清单，日期支持方向键移动、Enter 添加。
- **长期任务底栏**常驻在月历下方：输入没有具体时间的任务，按 Enter 添加。点击正文可修改标题、备注和清单，直接打勾完成；多项任务可在栏内滚动查看。它随上方清单筛选，切换月份不影响展示。
- 原来“未排期”里的事项自动显示在长期任务栏。编辑时取消勾选“长期任务（不设日期）”即可安排日期；日历事项也可以勾选这一选项，转回长期任务。原有标题、备注、完成状态和标识均保留。
- 日期标题旁的勾选图标可显示或收起日历和长期任务中的已完成事项。完成、删除均有 12 秒撤销提示。
- 点击“完整看板”展开原有的完整界面；在月历中按 `Ctrl + N` 添加事项，在编辑窗口中按 `Ctrl + Enter` 保存。
- 拖动挂件顶部可换位置，拖动边缘可调整大小；位置、大小独立于完整看板保存。
- 图钉只控制挂件置顶，默认关闭。旁边的方框按钮让挂件回到右下角，减号暂时收起到托盘。
- 挂件不占用任务栏按钮。点击托盘图标或桌面快捷方式可以唤回。
- **设置入口**：点击月历右上角的“设置”，直接调整开机自启动、当前窗口置顶、不透明度或备份数据。关闭设置后回到月历。

### 整理时：完整看板

点击标题栏“回到桌面”、最小化或关闭按钮，都会回到小挂件。两种界面共用同一份数据与编辑会话，切换前等待已提交修改保存，不会另建一套待办。

- **新建清单**：右上角“新建清单”，可命名并选择六种颜色。点击清单标题或右侧省略号可以修改、删除清单。
- **添加待办**：在卡片底部输入内容，按 Enter 保存。支持中文输入法。`Ctrl + N` 打开完整的新建窗口。
- **编辑待办**：点击待办正文，可修改内容、备注、开始及结束日期、重要标记和所属清单。日期留空的待办进入“长期任务”底栏。编辑窗口中可按 `Ctrl + Enter` 保存。
- **完成与恢复**：勾选后默认收起。在左侧“已完成”中取消勾选即可恢复。也可以用工具栏“显示已完成”同时查看。
- **移动与排序**：拖动待办到其他清单，或放在另一条待办前面。也可以在编辑窗口中选择所属清单。
- **删除与撤销**：编辑窗口中可删除待办；卡片底部可清理已完成。底部撤销提示保留 12 秒。删除清单前会确认。
- **搜索**：搜索正文和备注；`/` 聚焦搜索框，`Esc` 清空搜索。
- **窗口**：拖动顶部标题栏移动，拖动边缘缩放。图钉按钮控制置顶，偏好设置中可调整 75%–100% 不透明度。
- **托盘**：点击图标显示小挂件；右键可打开完整看板、把挂件放回右下角、切换挂件置顶或退出。偏好设置里的“退出应用”也可完全退出。
- **开机启动**：打包后的桌面版第一次运行会启用当前用户的 Windows 登录自启动，登录后显示小挂件，可在偏好设置中关闭。设置会读取 Windows 实际状态。开发模式不写入自启动。

这是一款可移动、可置顶的桌面窗口。普通模式下按 Win + D 会随其他窗口一起最小化；它没有嵌入 Windows 壁纸层。日期用于展示日历安排，不发送到期通知。

## 数据与备份

无需登录，运行时不访问网络。所有已提交的待办会立即保存到 `%APPDATA%/Mori/board.json`，先写临时文件并同步到磁盘，再替换正式文件。遇到不支持同目录重命名的 Windows 加密或重定向目录时，会在保留备份后复制并同步正式文件。`board.backup.json` 保留上一份保存内容。

主文件损坏时，会保留 `board.corrupt-时间戳.json` 并尝试恢复上一份备份。如果主文件和备份都无法读取，应用会提示错误，保留原文件，不会用示例内容覆盖数据。

升级到日历版会先保留 `before-calendar-upgrade-时间戳.json`。数据格式为版本 2，事项的 `start` 是开始日期，`due` 是结束日期；旧版仅有 `due` 的事项仍按单日处理。

偏好设置中可以导出、恢复 JSON 备份，兼容版本 1 和版本 2。恢复前会确认，并额外保留 `before-import-时间戳.json`。导出的备份含清单和待办；恢复不会改变当前窗口或启动设置。输入框中尚未按 Enter、或编辑窗口中尚未保存的草稿只在本次会话中保留。

## 开发

需要 Windows x64 和 Node.js 22.12 或以上。

```powershell
npm install
npm start
npm test
npm run test:e2e
npm run pack
npm run dist
```

Electron 首次运行会下载运行时。构建工具缓存放在项目的 `.build-cache`，构建结果在 `release`。图标已包含在仓库；仅重新生成图标时需要 Python 和 Pillow，运行 `python scripts/make-icon.py`。

实现采用 Electron + 原生 HTML/CSS/JavaScript，无运行时第三方 UI 依赖。渲染进程开启沙箱、上下文隔离、内容安全策略，文件读写只通过限定的 preload 接口完成。

自动化检查覆盖数据持久化、损坏恢复、非法数据拒绝，以及真实 Electron 窗口中的中文编辑、清单移动、拖放、完成恢复、撤销、搜索、设置持久化和窄窗口布局；也覆盖旧数据升级、月历点击添加、跨月跨年事项、日期校验、键盘导航、启动位置、双模式切换、独立窗口尺寸与置顶、重启及小窗口保存失败重试。日历截图在 `output/playwright/`。`npm test` 和 `npm run test:e2e` 使用临时数据目录，不修改日常待办或 Windows 自启动。

长期任务检查覆盖直接添加、无日期编辑、完成与删除撤销、重启恢复、输入草稿保留、日历与长期任务互转，以及 360 × 470 到 600 × 900 的窗口布局。

`scripts/verify-installed.cjs` 是安装验收工具，会启动已安装的应用并短暂切换真实的 Windows 自启动，最后恢复原值；仅在授权验收安装时运行。命令行 `Mori.exe --editor` 可直接打开完整看板，运行中的应用支持 `Mori.exe --quit` 退出。
